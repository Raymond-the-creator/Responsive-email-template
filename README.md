Brax Promo - Responsive HTML Email Template

A responsive, 600px HTML email template for Brax New Collection launch. Built with table-based layout for maximum email client compatibility (Gmail, Outlook, Apple Mail).

 Features
- Email Client Safe: Pure `<table>` layout, no div/flexbox - works in Outlook
- Mobile Responsive: `@media max-width: 600px` with `.stack-column` stacking
- Design:Inline CSS, `bgcolor` fallback, fixed `width/height` on images
- Luxury Branding:Black #000000 + Peach #FACCA4 contrast
- Accessible: `alt` text on all product images

Tech Stack
- Language: HTML4 Email compatible
- Styling: Inline CSS + Embedded media query
- Images: Cloudinary CDN (f_auto, q_auto optimized)
- Layout: Outer centering table + inner 600px email-container.
